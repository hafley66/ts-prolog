# Session: ts-prolog-type-level-sld

## Goal
Prove the TS type system can run the actual Prolog execution model (unification, clause DBs, SLD resolution, backtracking), map its recursion/fuel limits, and race it against SWI-Prolog.

## Current State
Done and committed through `8319e7d` on main at ~/projects/ts-prolog. All suites green under tsgo 7.0.0-dev + tsc 7.0.2. Three-lane SWI race verified exact answer agreement. Prior-art search complete: quadrant (engine=checker, subject=types) has only goals-only type-kanren as neighbor.

## Problem/Context
- typescript@7 = Go compiler, no JS API (lib/ is a shim); extraction uses ts5 alias (typescript@5.9.3) checker API.
- Fuel limits found empirically: ~100 instantiation depth (non-tail), ~1000 tail iterations per evaluation, ~5M global instantiation count. Chunked re-entry does NOT reset the 5M budget.
- Lazy `infer` captures stored in a subst build k-deep evaluation towers; killed machine v1.
- `Equal` dies comparing 30-deep cons chains (TS2321); deep answers unrolled via tail-recursive UnL first.

## Solution/Approach
- src/term.ts: Var/Term/Subst/Walk/Bind. src/unify.ts: Unify -> subst | false, no occurs check.
- src/solve.ts: naive nested Solve (reference impl, ceiling n=13 forward append).
- src/machine.ts: trampolined Run: explicit choicepoint stack [Goals, AnswerTerm, ClausesLeft], every recursive use in tail position; resolution by rewriting (unify vs empty subst, apply to goals+answer via RTerm, discard); RTerm = defunctionalized postorder rebuild with explicit stack. Ceiling n=60 deep / ~250 flat steps.
- Enforcement device for demos: phantom rest param `...proof: Cond extends true ? [] : [never]`; negatives pinned by @ts-expect-error.
- Race: SWI emits JSONL -> bench/gen_ts.py generates Equal assertions + query-only files -> tsgo verifies, tools/print-type.mjs (ts5 getTypeAtLocation + typeToString NoTruncation) extracts answers as JSON -> bench/compare.py diffs vs SWI. Type text of tuple/literal types is valid JSON.

## Key Insights
- Tail-call elimination in the checker is the trampoline; survives nested conditionals, `extends infer` chains, tuple destructuring. Non-tail = ~100 depth, tail = ~1000/evaluation.
- Subst must never store unforced projections; rewrite-and-discard beats global subst.
- Backtracking = try clauses in tuple order, concat per-branch solution tuples, [] = fail; no distribution tricks.
- Standardize-apart via template literal rename X -> X.<step>.
- 5M global instantiation count is the floor; no wrapper resets it. TS2589 = out of fuel.
- swipl 67ms startup vs npx+tsgo ~1781ms cold / ~400ms warm; net solve both tens of ms at race sizes.
- SWI and the machine agree answer-for-answer AND order-for-order (both SLD depth-first left-right).
- bench/race.sh reruns everything; results append to bench/results.jsonl.
